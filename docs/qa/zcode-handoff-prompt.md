# ZCode 外部试玩交接说明

请作为独立 QA 测试者，对本包中的 TCA Windows PC 原型执行人工全流程测试。只操作已导出的游戏，不修改游戏文件、源代码、测试数据或用户存档。

1. 阅读同目录的 `full-test-flow.md` 与 `../../design/gdd/combat.md`，按用例顺序测试。
2. 使用鼠标和键盘检查启动、手牌详情、出牌、反应槽、产物选择、清槽、结束回合、AI 行动、暂停、结果页与重开。拖放只作为快捷方式检查，不能作为唯一完成路径。
3. 每条用例记录 PASS、FAIL、BLOCKED 或 NOT RUN，并写明操作路径、预期、实际、复现次数和证据文件名。失败时保留未经裁切的截图/视频及原始错误日志。
4. 本包没有终局状态设置工具。需要 MT-07 特定初始局面的用例，如果无法通过正常游戏到达，应标 BLOCKED；不要伪造存档、手改资源或推断通过。
5. 性能预算是暂定值。只有能记录明确工具、测量口径和设备的数据时才填写性能结论；否则标 NOT MEASURED。
6. 完成后回传一份结构化报告及原始证据清单。区分真实 GUI 手工执行、自动化报告和未运行项目，不把 headless 启动成功写成 GUI 或完整对局通过。

构建号和 SHA-256 以包内 `BUILD-MANIFEST.txt` 为准。无需登录 Steam/Epic；此原型没有商店 SDK 或在线服务。
