# 关键流程冒烟清单

**状态：** 待战斗切片实现后执行。  
**目标平台：** Windows PC；键盘/鼠标主操作，手柄部分支持。  
**执行要求：** 记录构建号、Godot 版本、分辨率、输入设备、每项结果和证据路径；失败项先登记，不从报告中删除。

## 启动和导航

1. 冷启动 Windows 构建，主菜单显示完整，无导入占位图、错误字体或脚本异常。
2. 用鼠标和键盘分别进入一场新战斗。
3. 确认窗口尺寸变化后，主要 UI 不遮挡、裁切或失去操作焦点。

## 战斗关键路径

4. 查看一张手牌，卡名、元素、费用、效果与立绘一致。
5. 使用键鼠打出合法伤害牌，确认费用、手牌、目标 HP 和战斗日志一致变化。
6. 以能量不足、非法目标和不属于手牌的卡尝试操作，确认失败提示清楚且战斗状态不变。
7. 将两张有效元素牌放入反应区，查看产物，再确认合成、费用、产物与槽位状态正确。
8. 清空反应选择，确认卡牌回到原手牌且未扣费。
9. 结束回合，确认回合号、能量、一次性效果和敌方/玩家状态依设计文档推进。
10. 分别触发胜利和失败条件，确认战斗结束、结果提示和重开流程正常。

## 输入与稳定性

11. 键盘/鼠标组合可完成全部关键操作；拖放不应成为唯一路径。当前确认没有要求完全不使用鼠标的纯键盘通关。
12. 手柄导航测试在约定支持范围内通过，键鼠仍可随时完成全部关键动作。
13. 快速重复点击、取消反应选择、连续结束回合，不应重复结算或留下卡牌副本。
14. 连续完成 3 场战斗并返回主菜单，无崩溃、卡死、日志错误或明显资源泄漏。
